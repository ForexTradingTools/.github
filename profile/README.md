# ForexTradingTools

Free and open-source MetaTrader 4 and MetaTrader 5 indicators, built by a forex trader for his own charts. Each repository holds the MQL source and the released build. Downloads, screenshots and setup guides are on [forextradingtools.eu](https://forextradingtools.eu/en).
